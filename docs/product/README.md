# Site Scanning Product Guide

This guide explains the Site Scanning product from source-list creation through
public data use. It complements the operational instructions elsewhere in this
repository and the public
[Site Scanning program documentation](https://github.com/GSA/site-scanning-documentation).

## Documents

- [Architecture](ARCHITECTURE.md): system boundaries, components, runtime
  behavior, deployment, data model, and significant decisions.

## Suggested Reading Paths

**Engineer or operator:** Read the [Architecture](ARCHITECTURE.md) guide alongside the
existing [development](../development.md), [deployment](../deployment.md), and
[environment provisioning](../environment_provisioning.md) guides.

**Data consumer or analyst:** Refer to the public
[Site Scanning program documentation](https://github.com/GSA/site-scanning-documentation)
and its [Data Dictionary](https://github.com/GSA/site-scanning-documentation/blob/main/data/Site_Scanning_Data_Dictionary.csv).

## Scope And Evidence

These documents describe the implementation in this repository as of October
2026 and use the public program documentation and data dictionary as additional
sources. Where public documentation and code disagree, the documents identify
the discrepancy rather than assuming one source is authoritative for both
current behavior and intended behavior.
